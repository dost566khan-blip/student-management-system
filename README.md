# Student Management System

A beginner-friendly Student Management System built using Python and PostgreSQL.

## Technologies Used

- Python
- PostgreSQL
- psycopg2
- Git and GitHub

## Project Structure

```text
student-management-system/
│
├── main.py
├── database.py
├── requirements.txt
├── .gitignore
└── README.md
```

## Features

- Connect Python with PostgreSQL.
- Store student information in a PostgreSQL database.
- Insert student records into the database.
- Retrieve student records from the database.

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/dost566khan-blip/student-management-system.git
```

### 2. Navigate to the project directory

```bash
cd student-management-system
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure database credentials

Create a `.env` file and configure your PostgreSQL database credentials according to your `database.py` configuration.

Do not upload your `.env` file to GitHub.

### 5. Run the project

```bash
python main.py
```

## Database

This project uses PostgreSQL to store student information and Python to interact with the database.
